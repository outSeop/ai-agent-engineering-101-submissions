# R4 내부 구현·검증 — 2026-11-25

현재 등록 ID와 표시명은 outseop-r4다. R3·R4 매매 서비스는 중지했고 자동 시작을 해제했다. 수업 모델 검증을 위해 허용받은 별도 구매 불가 점검 접속도 검증 후 종료했다. 데이터는 보존했고 새 가게·새 실지갑을 만들지 않았다.

## 개발과 운영 역할

사용자 선택에 따라 Codex GPT-6.2 Sol이 구현했다. 수업 모델이 이 코드를 스스로 만들었다고 보고하지 않는다. 공식 Toolbox.forge로 생성·검증된 a2a_info v5, serve_checkout v5(기존 경로 폐기), shop_info v1을 중지된 기존 배포에 반영했다. 공식 키트7개 파일은 원본 해시를 유지한다.

실제 수업 모델 시험에서 응답 누락, 단위/권리코드 누락, 긴 checkout JWT 변형을 재현했다. 따라서 금융 문자열 복사를 모델에 맡기지 않는다. 관리 실행기는 공개 A2A의 검증된 코드와 모델의 읽기 전용 shop_info를 분리한다. 모델의 금융·프로필·신규 forge/read_tool 접근을 차단하며, A2A 실패도 고객 비밀을 모델로 넘기지 않는다. 기존 미니앱과 자동 매입은 관리 실행기에서 시작하지 않는다.

## 구현한 기능

- 실제 처리 지연에만 서명된 대기권, 발급 후120초 유효, 기준가1% 할인, 1회 사용과 영속 대기열.
- 정상 정산·인도와 체인 송금 검증 후 원 주문당1% 적립,7일 만료,다음 거래에서 기존 유효 잔액만 차감. 예약·확정·취소·부채상계와 환불 역분개를 같은 장부에 연결한다.
- 환불 접수는 공개 경로에서, 실지출·원송금인·48시간 초기 문제/확인된 미인도·기존 시도 대조와 승인 이체는 운영자 전용 경로에서 처리한다. 불명확한 송금은 새로 반복하지 않고 원 마커와 영수증으로 복구한다. 자동 환불 이체는 하지 않는다.
- 고객별 남은 마일리지/예약/부채/만료는 원장에서 계산한다. 방문은 인증된 접촉의30분 공백을 기준으로 한 세션 수이며 실제 물리 방문이 아니다. SKU·카테고리별 정산·유지·고장·환불 횟수를 분리한다.
- 가족관계·가구 구성·선호·소득분위는 직접 신고한 구조화 사실만 출처/시각/자기진술 표시와 함께 저장하고 정정·폐기 이력을 남긴다. 미상 소득을 구매액으로 추정하지 않는다. 시장 확인 구매자/지갑과 별도 권리계정은 연결 사실만 기록하며 권한이나 잔액을 합치지 않는다.
- 원가·수수료·적립 의무를 반영한 가격 하한, 현재 등급, unit 중복 판매 방지. 시장에 checkout 회수 기능이 없어 단순 만료·취소만으로 발급된 unit을 다시 팔지 않는다.

## 검증 결과와 범위

로컬37개: 구현 계약9, 프로필6, 런타임 권한경계4, 워커6, 별도 독립 구매계약9, 독립 프로필3이 통과했다. 별도로 공식 SDK와 공개 고객 코드 Visit.talk/Visit.buy를 이용한 모의 E2E에서4500→45적립→대기할인+마일리지4410→승인환불/역분개를 통과했다.

실제 수업 모델 API를 운영용 ManagedMind/ManagedToolbox와 연결한4개 시나리오(재고,혜택,금융경계,인증없는요구)도 모두 통과했다. 시장·RPC·고객·서명키는 격리 fixture이며 실거래가 아니다. 실제 운영 지갑으로 새 매입·판매·환불을 하지 않았다. 실제 R4 원장은 초기 지급1·매입1, 판매 정산0을 유지했다.

실패한 초기 수업 모델 장부와 실제 모델의 실패 응답도 비공개 runtime에 보존했다. 최초 자체 테스트 통과를 기능 완성으로 취급하지 않는다. 공개 검증 요약은 logs/internal-20261125/에 있고 실제 인증값/지갑/고객 DB는 Git 제외다.
