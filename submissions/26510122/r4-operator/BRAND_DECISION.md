# 가게 이름 확정: 생활

2026-11-25 사용자가 `생활`로 확정했다. 접미사 없는 두 글자가 가게 이름이다.

모아·오늘·생활·한칸 중 한 개를 고르는 가상 선호 조사에서 생활14표, 모아7표, 한칸6표, 오늘3표였다. 서브 에이전트3개가 각10개 페르소나 응답을 한 배치로 생성했다. 실제 고객30명이나 독립적인 API 호출30회의 결과가 아니다. 친숙하고 담백한 이름을 선호하는 페르소나 구성과 상품 설명의 어휘가 결과에 영향을 줄 수 있다. 사용자 결정의 참고 자료이며 실제 R4 고객 선호나 매출 효과를 입증하지 않는다.

실행 기본값은 `run_r4.py`의 `SHOP_NAME`, 응대 이름은 `../round-4/agent.json`의 persona에 반영한다. 서버 적용은 [인계 문서](SERVER_CODEX_HANDOFF.md)의 이름 적용 절차를 따른다. 기존 지갑·주문·대기표·마일리지·환불 의무를 이어 쓴다. 이 문서는 실제 서버 적용 완료를 뜻하지 않는다.
