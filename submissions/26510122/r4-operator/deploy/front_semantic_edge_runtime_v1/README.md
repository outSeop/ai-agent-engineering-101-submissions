The root-only transition helper defaults to inspection. --apply requires cards/wallet/URL/pending URL equal, exact original PID and old-edge PID alive, and ten continuous seconds of origin+old-edge TCP idle. Public marker failure attempts exact reverse only if the whole still-owned one-rule chain is unchanged.

This is optimistic compare-before/after protection, not an atomic conditional update against an unrelated concurrent iptables writer. Run it only with root-controlled exclusive network maintenance.
