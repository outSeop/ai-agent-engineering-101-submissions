# One class-model decision for representative card selection

HOST orchestration only, derived from native_card_reselection_v1. All native stage,
apply, refreshed-stock, signed origin, head/card, permission and publication checks
remain byte-original. Genuine apply_staged_card4 files are copied exactly. The
original full untrusted public comparison remains in the first official Mind context.

Model chooses exact SKUs once and calls the original stage tool directly. Listing
and goal say comparison is already supplied. Model max_tokens=800 and existing
35-second total model budget remain. The original official Mind.run_once is reused;
a private host-only completion signal stops it on the next completion entry after
valid native staging, avoiding extra compare/finish completions. The signal never
counts as a model call. If the first decision fails to stage, no second model request
is sent; the original failure and cooldown apply. No host SKU ranking is added.

bootstrap.py verifies this manifest and the original price_context_runtime_v8b
package, reuses its card-specific exact native_card_keeper_v1 helper and archived
v5 filesystem binding, then selects this immutable card entrypoint. Customer cache
service remains on v8b; main/front services and financial tools are untouched.
