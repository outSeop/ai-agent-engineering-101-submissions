# Future demand observer and public market projection — host infrastructure

This separate internal service makes no model call, joins no market, publishes no forum message and purchases nothing. It preserves original SDK7, dispatcher/refund/worker, all existing services/tunnels/task stores and paused Codex automations. It only reads future appended request traces, writes sanitized public source files and invokes a separately genuine no-wallet recorder for the new demand database. Do not activate until the root reviews genuine recorder pins and demand exclusion consumption.

Bootstrap verifies this entire package before importing host code. CLI: run_observer.py --package-manifest-sha THIS_SHA --recorder-forge-sha GENUINE_RECORDER_FORGE_SHA . Default is check-only; --run starts polling. Recorder source must already be installed at registered round-4/tools/record_stock_request and permission must be exactly no network/identity/wallet/handles/exec, pay_limit0, write[state/r4-demand]. The SDK ordinary Toolbox.run is used, not call (no index update). No Signer server or wallet is created, and token/address maps are empty. The explicit capability-denial stub exists only for original SDK compatibility.

The trace reader fences at startup EOF and never replays prior raw history. Rotation/truncation/regrowth fences anew; stable request refs deduplicate. Only future customer events enter RAM. A customer_received event ends the answered turn even if its SDK task remains input_required; wait120seconds before ingestion and recheck the trusted health registry plus exact17 old operator refs. Caller metadata/self-labels are ignored. Only structured final semantic args with validated success/no_match are forwarded; unsafe/unsupported semantic outcomes are skipped. No raw text/actor/Model thought is written to host metrics. Native input text exists only in RAM and local SDK stdin.

Health registry is resolved from operator/runtime/r3-stock-latest-path.txt, then health-probes.jsonl. A probe match requires exact textSHA and at-2<=eventTime<=ended_at+2. Successful native storage yields hash-only completion metadata retained6h, allowing later health classifications to generate stock-demand-exclusions.json. event_refs in that snapshot are ACTUAL database event_hash values SHA256(b'r4:stock-request:event:v2\x00'+input_event_ref.ascii), not raw internal refs. Native must compare directly without rehashing. If the native consumer cannot read a fresh exclusion snapshot, request_influence must be disabled; market-only opportunities are independent. A120second delay alone is not absolute proof of external buyer identity. All demand remains weak interest, not purchase promises or proven sales.

Public GETs use only fixed market endpoints, no authentication, redirects, proxy credentials, buyers, wallets, tx/order/unit raw references. Ledger pages use after=-500/-1000/-1500/-2000, at most2000 events, sequence deduplication and conflict rejection. complete=true means the observed contiguous sequence reaches back1hour; otherwise partial is explicitly false. No6hour coverage claim is made. Catalogue retains all at most10000 rows; whitespace only is normalized, and invalid/empty/>512/control/duplicate SKU makes the whole source unavailable rather than silently dropping rows. Two projected source files are capped2MiB each, TTL150s. Native computes p10/bands/eligibility/priority; host computes none. Missing broken/sealed flags stay null. amount is product price in credits according to original dispatcher.verify_settlement, while separated fees stay separate.

Native statuses recorded/duplicate are distinct from insufficient_evidence and SDK errors. Only transient catalog/storage/call failures receive at most2 additional attempts with the same hash and60second backoff; all text remains ephemeral and expires after15minutes. Metrics never imply an insert just because the SDK call succeeded. Recorder2 known limitations are not hidden: broad ambiguous/no-match nouns may still yield insufficient_evidence until a genuinely forged repair supports them.

QA uses synthetic temporary roots and fake callbacks/network only. No production trace replay, actual native recording, model, wallet, service or financial action was used. A separate genuine-recorder/current-public-catalogue admission check and native exclusion join check remain root activation gates. Unit template is an install template only; no service has been started by this package preparation.
