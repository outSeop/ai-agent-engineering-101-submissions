# 미발급 문법 후보: 합성28 통과, 실제 문의 실패

fact_parser_draft.py는 수업 모델이 작성한 순수 문법 정규화 함수다. 공식 SDK의 임시 d 경로로 검사했으며 새로운 forge.json을 만들지 않았다. 실제 검색·렌더러는 기존 모델 작성 도구를 기계적으로 재사용했다. 함수가 스스로 검증된 상품 답변을 꾸며내는 후보는 거절했다.

합성 SDK 입력28개는 통과했다. 이는 새 고객 요청에서 모델이 올바른 action을 고르는 검사와 다르다. 실제 실패 문의는 원문을 바꾸지 않은 로컬 재생에서 여전히 실패했다. 원문을 지우거나 실패 사례를 빼서 통과시키지 않았다.

따라서 이 함수는 운영 도구가 아니며 공식 발급·설치·매입·송금을 하지 않았다. 외부 서비스의 semantic9를 유지한다. 실제 문의 도입부의 제한된 내부 검토 승인이 필요하며 고객 원문이나 모델의 비공개 추론은 이 디렉터리에 포함하지 않는다.
