# 최소 모델 왕복 검증

공식 Mind가 GPT-6.2 Sol CLI 개발 연결에서 작성한 public_catalogue v6를 검증했다. 첫 v6 공식 자체시험은 쌀 대안의 적합 근거 분류 assertion에서 실패했다. 실패한 제출과 공식 관측을 같은 격리 개발 대화에 넘겼고, 두 번째 실제 forge가 통과했다. 최종 자체시험, 원본 응답 해시, 기존 실패/성공 시각은 safe-v6-provenance.json에 있다. 비공개 대화 원문이나 추론은 포함하지 않았다.

동일 source의 일반 SDK 호출에서 백미 5kg에 대해 쌀 5kg 대안, 견과, 미확인 돼지고기, 엄격 등급과 정형 SKU의 공개 응답을 합성 재고로 검증했다. 준비 도구에는 금융 실행 권한이 없다. 대안 및 엄격 요구의 종합 답변은 모델의 선택이 필요하다. 모델 장애의 도구 복구는 안전한 단일 범위 공개 조회에만 답한다. 카테고리 전체 부재, 지원하지 않는 제약, 다품목 조건을 추정하지 않는다.

호스트 테스트는 순수 조회의 구형 사전조정 생략, 정확 SKU의 모델 0회, 일반 후보의 모델 1회, 한 번의 수정 허용, 보호된 요청의 도구 fallback 차단, 예약 상태의 현재 등급, 스냅샷 SHA 결합을 검증했다. 이전 v4f 동작 호환 시험 17개도 통과했다. 새 tool 소스와 호스트의 고정 해시는 deploy/public_catalogue_runtime_v6/MANIFEST.json에 명시했다. 실제 운영 전환은 별도 작업이다. 후보 launcher diff는 메인 런처를 향한 참고 자료이며 배포 스크립트가 아니다.

재현은 운영자 디렉터리에서 PYTHONPATH=../round-4/codex-r4:kit 및 .venv/bin/python -B로 시험 스크립트를 실행한다. SDK 시험에는 운영자 디렉터리와 deploy/public_catalogue_runtime_v6를 차례로 넘긴다. 공개 배치의 두 호스트 시험은 보존된 테스트 본문의 패키지 경로만 제출 위치에 맞춰 변경했다.
