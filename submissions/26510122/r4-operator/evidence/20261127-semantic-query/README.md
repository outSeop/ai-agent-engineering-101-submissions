# 유사어 조회 도구 검증

공식 Mind가 유사어 후보 조회를 독립 도구 semantic_candidates로 작성했다. 최종 배포 후보는 semantic_candidates v2와 변경하지 않은 public_catalogue v8을 함께 사용한다. 통합 카탈로그 v9 시도는 타임아웃으로 실제 forge에 이르지 못했다.

v1은 SDK 자체 시험을 통과했으나 응답에 공개 SKU가 없어 후보로 보존했다. v2는 검증된 공개 SKU와 해당 SKU로 구매 조건을 다시 문의하는 안내를 표시한다. 최종 영업 로직의 v1·v2 차이는 표시와 길이 제한 처리에 국한된다. 이미 고정된 기존 카탈로그와 금융 처리 규칙은 그대로다.

모델은 준비 검색에 정보가 부족한 공개 문의에서 검색어를 최대 2개 제안한다. 도구가 실제 공개 재고와 원문 조건을 대조한 뒤 비구속 후보를 답한다. 이 경로로 대화 상품을 자동 저장하거나 결제권을 발급하지 않는다.

시험은 운영자 디렉터리에서 PYTHONPATH=../round-4/codex-r4:kit 및 .venv/bin/python -B로 재현한다. 두 SDK 시험에는 운영자 경로와 deploy/public_catalogue_runtime_semantic_v2를 순서대로 준다. 호스트 모의 시험의 패키지 경로만 공개 위치에 맞췄다. 비공개 대화, 운영 고객 원문, 자격증명 및 내부 원장 데이터는 포함하지 않았다.
