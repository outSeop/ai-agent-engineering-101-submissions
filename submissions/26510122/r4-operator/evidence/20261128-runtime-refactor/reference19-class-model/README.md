# 실제 수업 모델의 신규 도구 사용 확인

고정된 JSON을 반환하는 stub이 아니라 실제 market 수업 모델을 한 번 호출했다. 입력은 독립 합성 문장이며 실제 고객 원문이 아니다. 도구는 금융 인증이 없는 임시 root·NoWallet·별도 SDK task DB에서 실행했다. 실제 모델 API 인증은 별도의 Model 객체만 받았다.

모델은 콩음료 문의에서 search_similar_products를 선택하고 콩음료·두유 검색어를 냈다. genuine semantic19가 현재 합성 재고의 두유12팩, G00000001, B등급, 상품가8,010크레딧과 같은 스냅샷의 잔여 시간을 반환했다. 응답은 조건 미확정 참고 조회이며 결제서 미발급과 INPUT_REQUIRED를 유지했다.

모델10.1381초, 전체11.8637초, 모델1회·재호출0·금융 실행0이다. 실제 고객의 수신·정산·전환율 개선을 확인한 결과로 집계하지 않는다. private driver와 원 trace는 공개하지 않으며 safe 파일의 driver hash로 당시 버전을 식별한다. 같은 요청 안에서 native 결과와 최종 응답을 대조했고 시계가 다른 실행 간 reply SHA 일치는 주장하지 않는다.
