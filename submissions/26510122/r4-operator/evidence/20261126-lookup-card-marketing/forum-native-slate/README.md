# 포럼 후보 균형 검증

공식 Mind가 GPT-6.2 Sol CLI 개발 연결에서 prioritize_forum_candidates를 작성하고 공식 forge를 호출했다. 첫 자체 시험은 실패했고, 두 번째 시도가 v1을 설치했다. 도구 원본 네 파일과 공개 가능한 검증 요약을 보존했다. 원래 forge 및 모델 로그는 비공개로 보존하며 해시만 기록했다. 업스트림이 보고한 모델 ID는 제공되지 않았다.

포럼 후보를 구성하는 도구와 호스트 연결은 별개다. 공개 상품 사실을 만들고 게시 직전 재검증하는 기존 forum_marketing@5와 신규 연결 코드는 외부 작성이다. 최초 실제 수업 모델 검증은 변경 가능 DB를 여는 기존 reconcile을 지나 미해결 건 없음으로 종료했다. 두 번째 검증은 그 경로를 건너뛰는 읽기 전용 모드로 실행했고 실제 수업 모델이 B등급 버섯탕 2개입을 선택했다. 논리적 게시 선택 한 건을 기록했으며 실제 게시 요청은 0건이다. 최종 host2의 공개 게시물 등급 분포 추가는 원본 ManagedMind/MarketingCoordinator와 실제 SDK 도구 호출을 사용하는 모의 테스트로 확인했다. 실제 모델 검증은 분포 추가 전이었다.

MANIFEST.json은 배포 후보 전체를 확인하는 참조이며 이 증빙에는 생성 도구 원본과 안전한 결과를 담았다. BACKGROUND-PINS.json에서 별도 호스트 훅의 해시는 launcher가 검증한다.
