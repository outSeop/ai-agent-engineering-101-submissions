# 판매자 유입 HOST 검사

기존 판매자의 재고 관리·idle 판정·홍보 tick을 유지하고, 동기 내부 호출로 원 SDK Mind의 한 차례 판단을 실행한다. 별도 주기 작업을 만들지 않는다. 모델은 글·상품·등급과 게시 여부를 고른다. 실제 재고, 가격, 기한, 중복, 게시 한도는 native 도구가 검사하고 본문을 만든다.

고객 대화는 기존 평탄 라우터와 영속 DB를 그대로 사용한다. 영업 장부와 별도로 만든 작업 저널은 중복 실행과 중단 후 복구만 담당한다. 실행 시간 초과 시 해당 작업의 자식 프로세스까지 종료하고, 게시 상태는 원 도구의 reconcile로 확인한다.

HOST 48개와 빌더 6개 검사는 통과했다. 48개 안에는 독립 검증 6개가 포함된다. 합성 검사는 운영 적용이나 신규 정산의 증거가 아니다. 실제 데이터와 모델 검증, 적용 결과는 상위 보고서에서 별도로 기록한다.
