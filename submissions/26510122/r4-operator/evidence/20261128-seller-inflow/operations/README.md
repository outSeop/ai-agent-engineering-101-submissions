# 실제 게시와 전환 관측

초기 자연 실행의 게시를 공개 API·원 게시 원장·실제 Market 모델의 선택과 대조했다. 포럼 게시가 바이어의 조회·연락·구매를 뜻하지는 않는다. 첫 15분은 배포 전환을 포함한 초기 구간이며, 최종 고정 버전의 한 시간과 별도로 보존한다.

커피 문의에 원두커피를 선택한 사례는 상품군 관련성이 있었다. 샐러드·빵 문의에 커피믹스만 남은 사례는 모델이 보류했다. native eligible는 넓은 참고 후보 자격이며 의미상 관련성·구매 가능 조건 충족의 보증이 아니다. 모델의 선택과 도구의 사실 검증을 각각 확인한다.

고객 이름·문의 전문·모델의 생각 원문·지갑 키·거래 서명·비공개 DB는 내보내지 않았다. 최종 시간창과 문의·정산 수치는 관측 완료 보고서에서 확인한다.

최종 비교는 이전 19:29:48~20:29:48과 수정17 20:54:21~21:54:21 KST의 각 3,600초다. `FINAL-HOUR-COMPARISON-SAFE.json`은 실제 문의·결제서·정산·판매 기여액과 고정 시간창을, `ACCOUNTING-SAFE.json`은 별도 만료 손실과 회계 제외 범위를 담는다. `FINAL-METADATA-SAFE.json`은 47개 대화 조회 보존·호출 분류·자원 사용을, `OBSERVATION-SERIES-SAFE.json`은 81개 관측을 담는다.

`PUBLICATION-WINDOW-TYPES-SAFE.json`으로 이전 새 글 1건과 이후 답글 1건을 구분했다. 초기 비중첩 적용 구간 답글 1건을 더하면 수정 후 답글 총 2건이다. 원장의 생성 시각은 공개 서버의 노출 시각과 다를 수 있다. 문의·정산은 0→0이어서 전환 증가를 주장하지 않는다. 한 시간 후 관찰 프로세스는 종료했고 기존 셀러의 자연 운영은 계속한다.
