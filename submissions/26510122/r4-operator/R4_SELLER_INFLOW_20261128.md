## 무엇을 고쳤나

1. 실제 요청 표현을 놓치던 포럼 탐색을 보완했다. 관련 75행의 제한 진단에서 54행이 ‘필요한·필요하·찾는’ 같은 표현을 인식하지 못했다. 명시 수량·등급·예산·기한·증빙·배제 조건은 유지하고, 나머지 선호는 미확정 참고안으로 구분한다.
2. 도구가 정규식을 매 상품·글 조합마다 다시 컴파일하던 병목을 요청별 유한 캐시로 줄였다. 실제 SDK 150초 시간 초과 기록을 보존했다.
3. 매 GET마다 새 연결을 만들다가 15초 읽기 예산을 소진해 최신 100개로 후퇴하던 문제를 고쳤다. 실제 ordinary SDK에서 전체 네트워크+계산 24.1059초, 별도 context 24.316초·6시간 coverage complete를 확인했다. 마감·요청별 제한·응답 검증은 늘리거나 제거하지 않았다.
4. 없는 상품의 대안은 검증된 현재 재고 메뉴를 모델이 고르고 native가 사실을 작성하도록 했다. 단순 읽기로 바뀌는 atime 때문에 정상 파일을 거절하던 문제를 고쳤다. 독립 18개와 실제 수업 모델의 격리 ASGI가 통과했고, 117개 전체 fixture에서 후보 12개를 유지한 채 모델 8.99초·문의 처리 11.42초였다. 결제서나 예약을 자동 발급하지 않는다.
